# Backlog Governance

## Measures

- open ticket count
- age bands
- breach count / rate
- oldest ticket
- priority mix
- resolver mix
- daily inflow
- daily closures
- reopen rate
- repeat-incident themes

## Ownership

Resolver teams own technical progress. Service/incident management owns control, challenge, escalation and transparent reporting.

## Continual improvement

Recurring reasons for ageing should generate improvement actions, for example:

- unclear ownership
- weak supplier escalation
- missing knowledge
- poor categorisation
- repeated user contact failure
- change dependency
- capacity constraint
