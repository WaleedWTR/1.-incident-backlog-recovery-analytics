# Daily Backlog Control

## Daily review

Track:

- total open backlog
- breached tickets
- tickets approaching SLA
- oldest ticket
- high-priority tickets
- tickets without meaningful update
- supplier-blocked tickets
- unassigned / misassigned tickets

## Action discipline

Every aged ticket should have one of:

- active technical action
- user action
- supplier action
- planned change/fix
- valid monitoring period
- closure decision
- escalation

"Pending" should not become an indefinite storage state.

## Leadership view

Trend direction matters more than a single daily number. Review inflow, outflow and ageing together.
